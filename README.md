The goal of the game is to surround your opponent. 
Diagonal moves also count. The number of enemy
positions you manage to trap  is added to your score 
You have a time limit to play your round. 
If you don't play within a time limit,
the computer will continue
and can play up to three times. 
The high score is counted independently for each dimension. 
Reaching the high score is indicated by fireworks. 
The algorithm dynamically adapts to CPU performance. 
You can switch between 2 time  limits using [MODE] button.
This is indicated as < and <<.
No time limit mode is marked as |. 
A two player game is the third option of [MODE]. 
There are two color modes, classic and cyberpunk. Use [COLOR] button to switch
A random color is generated when clicking on the color circle. 
All sounds can be muted by clicking on the sound icon.
